Check the download

A damaged download causes strange errors later. Print the file's SHA-256 checksum and compare it with the one above; every character must match.

Windows

Open PowerShell (Start menu, type powershell):

Get-FileHash -Algorithm SHA256 "$HOME\Downloads\animux-genesis64-deb_28.iso"

macOS

Open Terminal:

shasum -a 256 ~/Downloads/animux-genesis64-deb_28.iso

Linux

Open a terminal:

sha256sum ~/Downloads/animux-genesis64-deb_28.iso
