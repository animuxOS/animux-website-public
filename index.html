Built by studios, given to everyone

The formats and tools of the big pipelines

The studios solved hard problems with their own tools, then released them as open source. Animux installs them, and its built-in guide explains each one with its sources.

Pixar · open source since 2016

OpenUSD

One shot, many departments: modelling, layout, animation and lighting each write their own layer of the same scene. Read by Blender, Houdini, Maya, Unreal and NVIDIA Omniverse.

Industrial Light & Magic · since 2003

OpenEXR

Keeps the real brightness of every pixel, so exposure can still change after the render, and stores render passes as layers for compositing.

Image Engine

Gaffer

Node-based lighting and look development from a visual-effects studio: one light rig can serve every shot of a sequence, rendered with Cycles.

Sony Pictures Imageworks · coming soon

OpenCue

The render manager Imageworks used on more than a hundred feature films, open source since 2019. Today Animux ships the Flamenco farm; OpenCue is coming soon.

Boot · install · render farm

From a USB stick to a room full of render nodes

The Animux boot menu. Every role is one entry away.

  1. Start it from a USB stickWrite the ISO to a stick and boot. The live system runs without touching your disk.
  2. Install it from the boot menuChoose Install Animux to Disk, or keep it beside Windows with dual boot.
  3. Turn computers into a farmBoot one PC as Render Farm Master and the others as Render Farm Slave. They find each other on the network and share the work.
