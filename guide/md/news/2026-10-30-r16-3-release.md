# Animux Genesis64 r16.3

> OpenToonz 1.8, the studio 2D animation program, and the Maya Workflow Kit for Blender.

Release **r16.3** (`animux-genesis64-deb_28.iso`, 12 GB) adds two programs for studio animators to r16.2.

## New

- **[OpenToonz](../software/opentoonz.md) 1.8**, the open-source Toonz used in studios: hand-drawn and cut-out animation with the Xsheet, scan cleanup, ink and paint, and node-based effects. Menu **2D Animation → OpenToonz**. Debian has no OpenToonz, so Animux builds it from its source code. A sample project is in `/usr/share/animux/samples/opentoonz`, and `animux-selftest` renders it.
- **[Maya Workflow Kit](../software/blender.md#coming-from-maya)** for Blender: Maya hotkeys, marking menus, shelf, Channel Box and the Maya layout, for animators trained on Autodesk Maya. It is **off** until you switch it on: menu **Animux Tools → Blender: Maya Workflow Kit on/off**.

## Fixed

- On screens of about 150 DPI (many 1080p laptops, virtual machines) OpenToonz would open at double size, with windows larger than the screen; it now follows the desktop's scale.

## Known limits

- The Animux repository is not online yet; updates for Animux packages come with the next release.
- The Maya Workflow Kit changes quickly upstream; Animux ships version 0.7.0, tested with Blender 5.2.
- Everything else as in r16.2.
