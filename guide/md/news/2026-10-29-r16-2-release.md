# Animux Genesis64 r16.2

> Claude Code in one step from the menu, and a boot menu without syntax errors.

Release **r16.2** (`animux-genesis64-deb_27.iso`, 12 GB) is a small update of r16.1.

## New

- **Claude Code in one step**: the menu entry **Animux Tools → Claude Code (AI agent)** (or `animux-mcp claude-code setup`) installs Anthropic's Claude Code with Anthropic's own installer, switches on the bridges for Blender, GIMP, Krita and Inkscape, makes a work folder and connects everything. It keeps the claude.ai connectors of your account (Gmail, Google Drive, ...) out. See [AI agents](../software/ai-agents.md#2b-with-claude-code). Claude Code itself is not on the ISO: it is Anthropic's program, needs a Claude account and the internet, and updates itself.

## Fixed

- The boot menu printed "error: syntax error" for a moment before it appeared (BIOS and UEFI). The ISO build now checks every boot menu file and stops on errors.
- GIMP's AI bridge hint names the right menu: **Tools → MCP → Start MCP Server**.

## Known limits

- The Animux repository is not online yet; updates for Animux packages come with the next release.
- Everything else as in r16.1.
