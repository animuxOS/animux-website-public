# Keyboard shortcuts

> A cheat sheet for the desktop and for the shortcuts animators use most in Blender, Krita, Pencil2D and Kdenlive.

## Desktop (Xfce)

| Keys | Does |
|---|---|
| **Alt+F2** | run a program by name |
| **Alt+Tab** | switch windows |
| **Alt+F4** | close the window |
| **Alt+F10** | maximise / restore the window |
| **Ctrl+Alt+D** | show the desktop |
| **Ctrl+Alt+T** | open a terminal |
| **Ctrl+Alt+L** | lock the screen |
| **Ctrl+Alt+Delete** | log out, restart or shut down |
| **Ctrl+Alt+← / →** | previous / next workspace |
| **Print** | screenshot (full screen); **Alt+Print** the window |
| **Ctrl+Esc** | open the program menu at the mouse pointer |

## Blender

| Keys | Does |
|---|---|
| Middle mouse drag | orbit the view; **Shift**+middle: pan; wheel: zoom |
| **Numpad 0** | look through the camera |
| **G / R / S** | grab (move), rotate, scale; then X, Y or Z to lock an axis |
| **Shift+A** | add an object |
| **Tab** | edit mode ↔ object mode |
| **I** | insert a keyframe |
| **Space** | play / stop the animation |
| **F12** | render the picture; **Ctrl+F12** render the animation |
| **N** | side panel (MPFB is a tab here) |
| **Ctrl+S** | save |
| **Ctrl+Z** | undo |
| **F3** | search for any command |

## Krita

| Keys | Does |
|---|---|
| **B** | brush; **E** toggles eraser mode |
| **[ / ]** | smaller / bigger brush |
| **Space**+drag | pan; **Ctrl+Space**+drag: zoom |
| **Insert** | new layer |
| **Ctrl+Z** | undo |

## Pencil2D

| Keys | Does |
|---|---|
| **N** pencil, **P** pen, **B** brush, **E** eraser, **K** paint bucket | tools |
| **, / .** | previous / next frame |
| **Enter** | play / stop |

## Kdenlive

| Keys | Does |
|---|---|
| **Space** | play / pause |
| **J / K / L** | backwards / pause / forwards |
| **I / O** | mark in / out point in the clip monitor |
| **Shift+R** | cut the clip at the playhead |
| **Ctrl+Enter** | render (export) |
