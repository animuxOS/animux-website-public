Storyboards, print and PDF

Plan your film with storyboards in Krita, Blender or Scribus, make an animatic, and lay out posters, scripts and portfolios as PDF.

storyboardanimaticScribusPDFplanning

Storyboards#

A storyboard is your film as a comic: one drawing per shot, with notes on action, camera and sound. Three ways on Animux:

Way How
Krita File → New → Templates → Comic Templates (panels ready). Or one image per shot in the Storyboard docker (Settings → Dockers → Storyboard), which can export a PDF.
Blender File → New → Storyboarding: draw with Grease Pencil on frames, with a camera per shot. Play it directly as an animatic.
Scribus lay out drawn panels with text boxes for dialogue and notes, export PDF for the team.

Animatic#

An animatic is the storyboard timed to the soundtrack: each drawing is shown as long as its shot will last. It shows whether the story works before you animate. Put the drawings and the recorded dialogue in Kdenlive and adjust the lengths, or use Blender's Storyboarding template.

Scribus#

Publishing → Desktop Publishing → Scribus makes page layouts: storyboard sheets, posters, comics, portfolios, festival press kits.

  1. File → New: page size (A4, Letter, or your own), margins.
  2. Draw image frames (I) and text frames (T), then File → Import → Get Image / Get Text.
  3. File → Export → Save as PDF (choose PDF/X for professional printing).

PDF tools#

  • Document Viewer (Evince) reads PDFs.
  • PDF Arranger: merge PDFs, reorder, rotate and delete pages by dragging.
